👁️ Project-Voir-Dire

Voir dire (vwar-DEER) — the legal process of questioning potential jurors to determine their suitability for a trial.

A Python implementation of a jury consulting scoring algorithm built around the fictional firm Prevail Analytics (PAC) — inspired by the real-world field of trial science and built as a Nucamp Python Backend Bootcamp project.

What is this?
Prevail Analytics is a fictional trial consulting firm that uses behavioral science, psychological profiling, and demographic analysis to predict jury verdicts and advise trial teams. This project builds PAC's core scoring system in Python — a weighted algorithm that profiles jurors, predicts plaintiff vs defense sympathy, and computes an overall verdict likelihood for a trial.
