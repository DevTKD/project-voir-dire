# 👁️ project-voir-dire

**Voir dire** *(vwar-DEER)* is the legal process of questioning potential jurors to determine their suitability for a trial.

`project-voir-dire` is a Python backend project that simulates the core scoring engine of a fictional jury consulting firm, **Prevail Analytics**.

The system uses synthetic juror profiles, weighted scoring rules, and explainable calculations to estimate whether a juror may lean more plaintiff-friendly or defense-friendly in a fictional civil trial scenario.

This is a learning project built for the Nucamp Python Backend Bootcamp. It starts with basic Python fundamentals and grows into a deployed REST API with database support, API key authentication, testing, and a CI/CD pipeline.

Every commit reflects a new backend concept learned and applied in public.
